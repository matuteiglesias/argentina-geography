# IGN department Geography Release — A10

Status: source snapshot pinned; normalized-content and relation proof are generated by the A10 source workflow.

## Scope

A10 adopts exactly one IGN administrative layer: **`ign:departamento`**. It is useful as a
second-order administrative reference while remaining bounded enough to relate against the already
released INDEC Census 2022 radio geography. This is not a provider-wide IGN ingestion framework.

## Native identity

The observed source properties are:

```text
gid, objeto, fna, gna, nam, in1, fdc, sag
```

`in1` is the release `native_id`: it is complete and unique across all 529 observed features and
contains the five-digit administrative code. `gid` is also complete and unique and is preserved as
a source/service identifier. Both remain inspectable. Names are deliberately not identity:
`fna` has 472 unique values and `nam` 447 for 529 features.

The source administrative vocabulary is preserved. `gna` contains `Departamento`, `Partido`, and
`Comuna`; A10 does not collapse these labels into a locally invented taxonomy.

## Geometry and QA boundary

Normalization does not repair geometry. Missing, empty, or non-areal geometry fails staging.
Source-invalid polygons, if any, remain in the Geography Release with
`geometry_role=source_invalid`; relation construction excludes them from the analytical target set
and reports that exclusion quantitatively.

The materializer also fails closed on:

- raw snapshot SHA/size drift;
- feature-count drift;
- missing required source fields;
- duplicate or malformed `in1`;
- drift in the source `objeto` or `gna` vocabulary.

## Distribution, attribution and limitations

Distribution mode is `official_remote_fetch`: the 140 MB WFS response is not committed to this
repository. IGN is credited as the source. Current IGN demarcation-layer metadata states free use
with appropriate citation of the Instituto Geográfico Nacional; A10 records that attribution
evidence without converting it into a broader license claim for unrelated IGN products.

The layer extends to the Argentine bicontinental/Antarctic representation. Census 2022 statistical
geography does not necessarily cover every IGN administrative target, so unreferenced targets are
expected relation facts, not errors. The source `fdc` field exposes multiple capture lineages and is
preserved.

## Relation boundary

The A10 relation binds this exact Geography Release to the exact released
`arggeo.indec.census.2022.radio` parent. It uses
`spatial_foundation.geography.relate_areal_objects`, retains N:M positive-area facts, adds target-side
overlap share only for quantitative coverage QA, and keeps unmatched/invalid cases observable.

Neither parent is mutated. The relation contains no preferred-provider decision, no one-target
assignment, and no Census geometry replacement.
